# Visionaries in Exile

This repository is now the public entrance and deployment scaffold for the one-to-one online restoration.

## Restoration Principle

The CD-ROM is a time-based, narration-based artwork. The original runtime remains the source of truth. A modern web rewrite is useful only as documentation, not as the artwork.

## Public Site

Netlify publishes `site/` as the public entrance page.

## Runtime

The real online player must run from a hosted runtime server. See `runtime-server/` for the Guacamole/RDP audio-streaming scaffold.
