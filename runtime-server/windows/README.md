# Windows Runtime Host

The Windows machine is the artwork runtime. It should not be treated as a development desktop.

## Requirements

- Windows Pro or Server with RDP enabled.
- QuickTime/Director dependencies installed.
- Preserved `Visionaries in Exile` payload available at a stable path.
- A launcher that opens the original projector directly.
- Audio confirmed through RDP before going public.

## Session policy

Start with one visitor at a time. After each session, reset the VM to a clean snapshot or relaunch the projector.
