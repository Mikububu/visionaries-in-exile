Architecture

Why not a Netlify-only rebuild?

Because this is a time-based, narrated artwork. If timing, sound, QuickTime behavior, and the original projector change, the work changes.

Final Path

  • Netlify hosts the public museum entrance.
  • A small runtime server runs the preserved Windows projector.
  • Apache Guacamole/RDP or WebRTC streaming carries video, input, and audio to the browser.
  • The original runtime remains the source of truth.
