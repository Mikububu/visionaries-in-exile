Current Decision

Netlify alone cannot faithfully run this narration-based Director/QuickTime artwork. The final online version needs a hosted Windows runtime streamed to the browser with audio.

  • Original projector, not a Claude-style reconstruction.
  • Audio carried inside the browser session, not leaking from a local VM.
  • One visitor session at a time until we scale safely.
